# 新 IDEA 与新增论文的 RAG 对照协议 v1

2026-10-20，执行前冻结。范围是预训练 ViT 参数高效适配的文献取证与研究设计，不运行 coding 或训练。

六个新增研究问题、十二个中英文证据查询固定于 `config/benchmarks/rag_incremental_v1.json`。
来源是此前真实获取的87篇论文快照；每个新问题再执行实时发现，最多新增两篇不同 PDF hash 的公开全文。
论文全文相对于本轮初始87篇判定为新增，不能把重新下载旧文件计为新增。每题获取失败仍保留。

检索前建立按页合并的连续文本段，保留原文节点、页码和 PDF hash。旧库不修改。
四个同语料、同查询、同返回数的检索对照：BM25关键词、神经向量、关键词+向量、完整神经混合+交叉编码器重排+MMR。
完整检索是项目 HybridRetriever，使用真实本地神经模型，禁止静默回退为 hashing。
在旧语料和增量语料分别运行，不用结果调参。

相关性评审看全部论文的全部提取文本（长论文分段），同时回答十二个查询，看不到系统名、排序和模型答案。
每个查询/论文标为0无直接证据、1局部支持、2直接支持；正标签必须给可逐字核验的文本段ID和原句。
论文级真值取各分段最高有效等级。它是穷尽本轮语料的模型银标，不是人工金标，也不把未下载论文计入召回率分母。
另对各系统前十文本段的并集做盲评片段相关性，用于片段排序指标；片段召回仅称池内召回。

指标：论文级 Recall@5/10（已标相关论文找回比例）、MRR@10（首个相关结果倒数排名）、
nDCG@10（相关程度越高、位置越靠前越好），片段级同名排序指标。
论文级排名按文本段首次出现去重，不用论文标签调整排序。
按十二查询宏平均，另列新增论文、中文/英文、逐 IDEA 结果；相关论文为空时标记不可定义并报告数量。
用按六个 IDEA 聚类的配对 bootstrap 95%区间，展示效应不确定性，小样本不承诺显著。

RAG消融：相同模型、问题、输出约束，对比无检索、BM25、完整神经RAG。证据字符预算相同，保留实际输入token。
输出必须区分论文事实、证据缺口和拟议实验。逐问题对三个匿名答案随机顺序盲评；另核验每条事实引用的存在与支持。
报告0–4分的正确性、问题覆盖、研究设计可用性，以及事实支持率、引用可定位率。无RAG仍可凭模型知识正确，不能因无引用直接把正确性记0。
这一消融的终点是研究证据答复，不替代此前完整冻结规格的端到端成功率。

速度单列：模型预热后，比较全量编码、仅编码新增段、持久索引复用的实测耗时和编码段数；
记录首次检索与重复检索，不把模型加载时间混为缓存算法收益。准确性排序和速度分别报告；神经系统可能比BM25更慢。

协议、代码、输入和模型名hash固定；请求、响应、预算账本、下载错误、全部逐题结果留档。
同一模型不同调用存在相关偏差；未评估专家金标、全球检索召回、百万篇规模、正式训练收益或公式解析准确率。
