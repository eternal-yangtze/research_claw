# 相同无检索对照的复用补记

2026-10-20，v2生成开始前记录。v2仅改变检索查询规划，不改变原始问题、生成系统提示、
模型和输出预算。无检索分支没有证据文本，因此其完整请求与v1逐字相同。
全部十二个无检索请求统一复用v1的原始缓存，不根据答案质量挑选；v1已保留生成费用、请求和响应。
这一补记将v2协议中的“重新执行三个生成对照”明确为：重新执行三组工作流，其中相同无检索请求允许缓存复用。
两组带检索的答复按各自新证据重新生成，三个匿名候选仍一起重新盲评。

工具 `scripts/share_rag_controls.py` 仅拷贝零证据、相同模型的完整请求对应缓存；
目标若已派发请求或已有结果则不覆盖。复用记录包含原请求和缓存的SHA256，写入目标 `shared_controls.json`。
暂未生成的原始对照会在其正常生成后统一补入，不更改其内容、不重新选择更好答案。
全部原始成本计入v1与v2的合计，v2缓存命中不重复计费。这提供相同的前后控制答案并减少无意义重复调用。
