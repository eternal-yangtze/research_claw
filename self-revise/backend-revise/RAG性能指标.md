# RAG性能指标与使用边界

统计截至2026-11-09，RAG实验阶段结束。正式库204份PDF记录、3020 Parent、10955 Child；PG向量副本0，Qdrant dense/sparse各10955点。PDF记录不是独立作品计数。本文保留负结果，不主张全局最优。

## 1. 数据集和证据口径

主证据目录：[expanded-rag-v20261109](rag-evidence/expanded-rag-v20261109/实验报告.md)。检索60题=48开发+12 held-out；生成46题=34开发+12 held-out。两侧共享41题，总共65个不同问题。题型覆盖单篇事实、跨篇、条件、排除、版本和结构，生成开发含5题不可答。held-out是跨题型划分，不是一个题型。

源论文条件化银标在被测召回前编写，同一参考用于对照。不是人工生成金标或独立公共基准；不是按论文完全隔离的盲测，存在一对相似度0.935的跨划分问题。相关文献标注不穷尽所有可接受来源，结构题主要验证物理页和结论位置，不能代表完整附录理解。开发选型后才运行held-out，未据其调参。

## 3. 生成侧：配对银标与真实RAGAS

配对盲评使用legacy_pair与anchored；开发仅29题可答，另5题单独检验拒答。以下不是RAGAS分数。

|指标|开发 legacy→anchored|held-out legacy→anchored|
|---|---:|---:|
|逐事实faithfulness|0.9911→0.9845|1.0000→1.0000|
|答案相关性|0.7679→0.8993|0.8292→0.8775|
|参考事实召回|0.6600→0.8386|0.7142→0.7975|
|精确引文覆盖|0.4655→0.5690|0.6389→0.7222|

开发faithfulness有效分母为legacy 28、anchored 29；其他开发项29，held-out各12。开发不可答两组均5/5拒答，仅代表这5题，不是通用拒答率。held-out参考事实提升来自1题改善、11题不变，bootstrap 95%区间为[0,0.25]，不能称广泛统计显著。

真实RAGAS 0.4.3在held-out 12题对dense和anchored运行四项，96/96项评分成功，失败0。证据：[ragas-summary.json](rag-evidence/expanded-rag-v20261109/ragas-summary.json)。

|RAGAS指标|dense|anchored|含义|
|---|---:|---:|---|
|Faithfulness|0.9085|0.9156|答案陈述是否能由给定上下文支持|
|Answer relevancy|0.5724|0.7358|答案是否回应问题|
|Context precision|0.5889|0.6625|靠前上下文对回答的有效性|
|Context recall|0.5417|0.7083|参考答案所需信息被上下文覆盖的程度|

0.9156不是“91.56%的答案完全正确”。评分使用同模型体系辅助银标，不能替代人工独立复核。相同legacy答案在三方和配对评分中的开发相关性可从0.9166变为0.7679，反映judge敏感性；以配对、原文引文和RAGAS交叉看，不挑最高评分作结论。旧6题结果与本次参考协议不同，不直接作时间序列提升对照。

## 4. 最重要的负结果及原因

anchored跨篇参考事实覆盖开发约0.54、held-out约0.45，仍不足以自动做完整跨篇结论。可能原因是有限上下文中多篇条件竞争、局部精排偏好、解析结构缺失及参考事实粒度差异；不能仅用一个总分证明唯一原因。高忠实性与低完整性可以同时成立，意味着“说的有根据，但漏了该说的”。人工入口见[人工抽查窗口](rag-evidence/expanded-rag-v20261109/人工抽查窗口.md)，含10个低覆盖案例、21个源位置。

150/10955个Child超过512 tokens（约1.37%，最长1693），有embedding截断风险。后置附录、表格公式和版本识别是其他缺口。曾试纯结构Child，直接证据命中6/8→3/8，故不推广；这不是语义结构普遍无效的证明。已修复Parent聚焦丢Child、指定论文漂移和评分引用ID格式解析问题，保留原始错误与修正证据。

这些缺口确实限制自动综述、创新裁决与数学结论完整性，但不阻断个人论文导航和可核查问答。合格使用方式是按篇查证、追问遗漏条件、对关键结论打开PDF核对；不是直接把生成结果写成论文事实。没有验收长期记忆/上下文的指标，不能用RAG成绩代替。

## 5. 增量、性能与容量边界

原证据：[final-rag-v20261109](rag-evidence/final-rag-v20261109/)。194份原库备份位于`internal_experiments/assets/rag_backup_194_v20261109`；已做哈希与备份可读核对，未宣称隔离恢复演练完成。

## 6. 结论与证据入口

可以作为本人科研论文库工具使用，适用范围为定位、阅读辅助和有来源的初步问答。不能交付成自动创新性证明、完整综述或生产级多用户服务。RAG实验到此收尾，后续只修真实使用问题。

复核脚本保留`self-revise/backend-revise/scripts/evaluate_rag_expanded.py`、`report_rag_expanded.py`、`audit_rag_expanded.py`及有意义的对照代码。逐题原始答案、评审、冻结集、失败诊断、token审计、采纳决策和哈希清单位于扩展证据目录；旧对照/消融与必要金银标均保留。完整链路见[readme_rag.md](readme_rag.md)，后续见[v20261109.md](v20261109.md)。
