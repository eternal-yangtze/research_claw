\sectionTitle{项目经历}{\faCode}
%======================================================================
\begin{itemize}
\item \textbf{ResearchClaw：面向个人论文库的科研 Agent}\hfill 独立开发

\textbf{项目概述}: 面向时间序列压缩与误差控制研究，基于 204 份 PDF、约 1.1 万个检索片段，支持论文问答、idea 分析、文献扩展与基线设计；采用 LangGraph 单 Agent 与动态任务 DAG，随用户追问和研究约束变化调整检索与计划。
\begin{itemize}
\item \textbf{离线知识构建与增量索引}: 实现 PDF 清洗、质量分级与父子分块，以小块召回、父级上下文补全及章节信息辅助定位；内容哈希去重，复用既有解析与向量。12 份增量输入去重后新增 10 份，构建约 101 秒，复用 10,337 条向量；无变更检查约 0.49 秒。
\item \textbf{混合检索与评估驱动优化}: 构建 Query 改写/扩展、Qdrant 向量与 BM25 双路召回、RRF 融合及 Cross-Encoder 精排链路，保留页码与原文引用。自建 60 题检索集的 12 题验证集上，MRR@5 相比仅向量检索由 0.6944 提升至 0.9583；生成侧 12 题验证集上，相比原始问题仅向量检索，RAGAS 答案相关性由 0.5724 提升至 0.7358，忠实度为 0.9156（LLM 银标）。
\item \textbf{Agentic RAG 与动态编排}: 将检索、原文回读与文献渠道查询封装为工具，由 Agent 根据证据调整 Query、补充检索或提出研究建议；支持任务依赖、局部重规划与产物校验。对照单 Agent 与 Planner/Worker/Reviewer 三角色，在本地 24 个科研任务上采用 LangGraph 单 Agent，银标成功率 95.8\%，平均耗时 50.45 秒。
\item \textbf{单会话记忆与上下文管理}: 结合最近完整轮次、BM25 问题驱动历史召回、对话锚点与显式 Session State，保留研究约束及用户更正。LongMemEval 单会话 oracle 全量 156 题上，相同 4096 token 窗口预算下，相比“最近轮次 + 关键词触发历史摘录”，银标准确率由 48.1\% 提升至 86.5\%。
\item \textbf{工具治理与持久化恢复}: 基于官方 MCP SDK 实现 stdio 论文只读服务，Skills 按需发现、加载与调用；PostgreSQL 保存正文、会话与检查点，Qdrant 专职论文召回。实现身份/会话隔离、操作二次确认、执行预算与结果复用，对效果不明确的写操作停止自动重放，并保留 Coding Agent 确认交接入口。
\end{itemize}
\end{itemize}
