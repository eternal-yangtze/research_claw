\sectionTitle{项目经历}{\faCode}
%======================================================================
\begin{itemize}
\item \textbf{ResearchOps Agent Runtime（面向科研任务的 Agent 执行平台与 Coding Agent）}

\textbf{项目概述}: 独立实现统一 Agent Runtime，支撑命令行与 Web 复用会话管理、模型调用、工具执行、Skill 按需加载、任务记忆和运行记录。在其上构建面向科研任务的 Coding Agent，衔接“读材料 $\rightarrow$ 检索证据 $\rightarrow$ 编译方案 $\rightarrow$ 跑验证 $\rightarrow$ 输出报告”的任务闭环。配套可扩展的语料库、idea集、离线评测矩阵及冻结评测协议。
\begin{itemize}
\item \textbf{工具调用治理}: 面对工具调用规则容易堆进 prompt、模型可能误用工具或反复重试的问题，梳理上下文构建、模型调用、工具执行与结果写回流程，接入工具检查、工作区路径校验及步数与重复调用检测，使工具调用从“模型自觉遵守”转为运行时约束。
\item \textbf{RAG 与证据组织}: 面对单一检索难以兼顾术语和语义、相近段落容易占满上下文的问题，组合 BM25 与向量召回，经 cross-encoder 重排和 MMR 去冗，再由 Fusion 融合候选并逐字校验引用，支持按需取证与原文回读；固定 94 篇语料上，nDCG@10 从 0.690 提升到 0.749，Recall@10 从 42.21\% 提升到 42.89\%（LLM 银标）。
\item \textbf{上下文管理与按需加载}: 面对长任务中历史源码、工具输出和文献反复挤占上下文的问题，截断长输出并保留预览，省略历史源码正文但保留文件回读，按身份卡、筛选卡、全文档案、问题综合分层压缩文献；Skill 经发现、加载、执行按需提供正文，相对全量加载在两个成功重复对照中使初始提示 token 减少 68.7\%，平均总 token 减少 57.4\%。
\item \textbf{任务状态、成本与运行复盘}: 面对长任务中断后难以续做、调用成本难以核对、失败后难以复盘的问题，持久化会话与任务状态支持 Coding 续做，请求前预留预算、返回后按 usage 结算并保留失败请求的未知成本预留，结合 trace 与离线评测矩阵关联执行过程、成本和效果，使运行可恢复、可对账、可复盘。
\item \textbf{代码执行与验证闭环}: 面对生成代码可能影响宿主环境、完成状态不能由模型自判的问题，在断网、非 root、限制资源的 Docker 容器中运行代码，源码、数据与 verifier 只读挂载，由外部 verifier 重算指标并反馈失败以驱动修复；工作区锁与原子 checkpoint 保存进度，plan hash 及源码与 harness 指纹校验恢复和完成条件，支持中断后检查现场再续做。
\end{itemize}
\end{itemize}
